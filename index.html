Q&A

Do I need to install an app? +

Unfortunately yes however the app is very small, offline and extremely fast.

Which phones does this work with? +

Any Android phone with an NFC reader, you can check by searching up "Does my (phone model) have an NFC reader?"

What if my timetable changes next term? +

If your timetable ever changes please contact timetable.support.app@gmail.com with a picture or text based version of your new timetable for an app update.

Do I need the subscription for it to work? +

Absolutely not, the subscription is there to support my project while giving you fresh new updates and prioritised feedback from you.

What if I lose my TimeTable Tag? +

Order a new tag at the same price and you're back up and running. Your subscription stays.

Will iPhones ever be supported? +

I'm working on bringing the app support to IOS, however everything is ran by one person so it may take some time, stay tuned for more updates.
